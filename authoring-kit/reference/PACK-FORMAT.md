# Pack format

A pack is a JSON object with an `id`, `version`, `requires` and `content`. Its `requires.storyBlock` is a version range; optional `requires.capabilities` lists capabilities the pack needs, such as `story-director`, `scene`, `inventory` or `data-modules-v1`.

Content can include places, routes, events, items, creatures, quests and data modules. A pack can also provide a calendar, weather, currency, screens and a start state, and a rank for the player's character: `"content": { "you": { "rank": { "label": "Guild rank" } } }` (label 1 to 30 plain characters, no `< > { }`; unknown keys under `content.you` are refused). Without it the game has no rank. See `DATA-MODULES-FORMAT.md` for data module fields and `LIMITS.md` for size bounds. The checker is the final authority: run `node check.mjs work/pack.json`.

Story Block 2.31.0 supports `content.names`: `{ "banned": ["Elara"], "river": { "regions": ["River"], "given": ["Wenna"], "family": ["Lockwright"] } }`. Each culture needs nonempty `regions` and `given`; `family` and `banned` are optional. `names` and `banned` are reserved culture ids. A Director with its names part may suggest given names for matching regions.

An optional top-level `ripples` object has `powers: [{ id, name, base, aliases?, factions?, givers?, npcs?, standing?, standingBase? }]` and optional `tiers`, `caps`, `standingModule` and `worldDirections: [{ event, favours, unless? }]`. NPC entries are `{ name, weight? }`. Story Director computes sway; see `docs/v2/PACKS.md` for scoped selection and fallback. An invalid names or ripples section is ignored and reported as a warning while the rest of a valid pack installs.

Once events may give the same `decision` slug to mutually exclusive alternatives. When earlier history changes, the host reselects that decision where its receipt was stored. Give the pack a `requires.storyBlock` range of at least `^2.31.0` when using these fields.


Event conditions can use `region(name, ...)` (Story Block 2.31.1): true when the scene's place is in any of the 1 to 16 named regions (exact names, as `query('scene.place').region == name`; false with no place). It replaces a chain of `||` over regions, so one event can cover several regions and fire once. Each name is at most 200 characters; the whole condition keeps its 1000-character limit.

A pack can list a hand-written cast in `content.cast`: people with a look (the body) and what they wear, a voice, a personality with behaviour levers, mannerisms and how they treat the player character, a start (place, goal, routine), what draws them to the party, starting meters, stages, fields and secrets. Each may name a portrait image (`"portrait": "fenna.webp"`, WebP, PNG or JPEG of up to 10 MB, at most 32 per pack; Story Block makes one over 150 KB smaller when it imports it) that comes beside the pack: pick `pack.json` and the images together when importing, or ship one `.zip` with `pack.json` and a `portraits/` folder. A secret opens by a meter value (`meter` and `at`), by a story event (`when`), or by both, in which case it opens at whichever comes first; it needs at least one. See `docs/v2/PACKS.md` "The cast" for every field and `LIMITS.md` for the bounds.
