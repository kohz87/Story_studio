  • Markup: each divider is role="separator" with aria-orientation="vertical", aria-valuenow, aria-valuemin, aria-valuemax, an aria-label and tabindex="0". The markup in these states is the real attribute set.
  • Keys: arrows move 16 px, Shift + arrow moves 64 px, Home and End jump to the min and max, and double-click or Enter puts the column back to its default width (Enter is there because double-click needs a pointer).
  • Grip: hidden at rest (a one-pixel line, as today), shown on hover and on keyboard focus. The focus ring is Studio's usual 3 px accent outline.
  • Remembered per device: the two widths are kept in this browser's storage on this device only. A different device starts from the defaults. If storage is blocked, the defaults are used.
  • Screen sizes: from 1101 px up both dividers show. From 601 to 1100 px the inspector is the overlay it is today and only the rail divider shows. At 600 px and below the columns stack and there are no dividers (see the phone file).
